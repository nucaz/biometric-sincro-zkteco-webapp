Importar empleados desde Excel

Descargar plantilla

El archivo debe tener una primera fila con encabezados. Se reconoce cualquiera de estos nombres (sin distinguir mayúsculas):

  • Código / DNI: columna "codigo", "código", "code", "dni" o "id" (opcional, pero necesaria para que no se dupliquen empleados si vuelves a importar, y para poder asignarles horario después por Excel).
  • Nombre: columna "nombre" (obligatoria si no usas "nombre completo"). Si además incluyes "apellido paterno" y/o "apellido materno", el nombre completo se arma solo uniendo las tres; si no, "nombre" se usa tal cual como nombre completo.
  • Nombre completo: columna "nombre completo", "full_name", "name" o "empleado" -- alternativa a lo anterior, un solo campo con el nombre ya completo.
  • Datos opcionales: "apellido paterno", "apellido materno", "fecha de nacimiento" (AAAA-MM-DD), "celular", "correo personal", "correo corporativo", "direccion", "area", "sede".

Si el código de una fila ya existe en el maestro, se actualiza con los datos que traiga esa fila (una columna que no viene en el archivo nunca borra lo que ya tenía guardado); si no existe, se crea un empleado nuevo. Las filas sin nombre se omiten.
