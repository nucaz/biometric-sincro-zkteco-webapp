Importar empleados desde Excel

El archivo debe tener una primera fila con encabezados. Se reconoce cualquiera de estos nombres (sin distinguir mayúsculas):

  • Código / DNI: columna "codigo", "código", "code", "dni" o "id" (opcional, pero necesaria para que no se dupliquen empleados si vuelves a importar)
  • Nombre: columna "nombre", "nombre completo", "full_name" o "name" (obligatoria)

Si el código de una fila ya existe en el maestro, se actualiza el nombre; si no existe, se crea un empleado nuevo. Las filas sin nombre se omiten.
